My Website – HTML & CSS Learning Project
This project is part of my HTML and CSS learning journey. It contains a simple webpage built to practise core web development concepts such as structure, semantic tags, text elements, buttons, inputs, and basic layout.

📄 Project Overview
The webpage includes two main sections:

1. Welcome Section
A heading introducing the platform

A short message granting access

A Sign Up button

Input fields for:

Username

Password

File upload

A link-style message for users who already have an account

2. About Us Section
A heading describing the company

Text explaining the purpose of the platform

A brief introduction to aerospace‑grade robotic parts and robotics learning

🎯 Purpose of This Project
This file helps me practise:

Basic HTML structure

Headings and paragraphs

Buttons and input fields

Organising content into sections

Building simple, readable layouts
