📄 Google Homepage Clone
A simple Google‑style homepage built using HTML as part of my web development learning journey.

🚀 Project Overview
This project recreates the basic layout of the Google homepage using only HTML.
It includes:

A full‑width header image

A search input field

Two buttons similar to Google’s interface

Links to additional pages (work.html and blog.html)

A clean, minimal layout to practice structure and tags

This project is part of my HTML & CSS learning and helps me understand how real websites structure their content.
