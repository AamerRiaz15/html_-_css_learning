📄 README — Paragraph With Cool Formatting
📌 Overview
This project displays a creatively written paragraph inside a styled card component using HTML and CSS.
The goal was to practice:

Structuring simple HTML content

Applying CSS to create a card-style layout

Using padding, borders, and rounded corners

Keeping HTML and CSS cleanly separated

It’s part of my ongoing HTML & CSS learning journey.

🧱 Features
A centered card-style container

Light gray background

Rounded corners

Thick black border

Comfortable padding for readability

A fun, poetic paragraph displayed inside the card

🧩 Technologies Used
HTML5

CSS3

No frameworks or JavaScript — just fundamentals.
