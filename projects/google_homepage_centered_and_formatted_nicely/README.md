📄 README — Google Homepage (Centered & Formatted Nicely)
📌 Overview
This project is a simple recreation of the Google homepage layout using HTML and CSS.
The goal was to practice:

Structuring a clean HTML page

Centering elements properly

Using CSS to style images, inputs, and buttons

Understanding how margin: auto and text-align: center behave

Linking external pages (work.html, blog.html)

It’s part of my HTML & CSS learning journey.

🧱 Features
Centered Google-style logo

Centered search bar

Two buttons styled like Google’s layout

Links to additional pages:

Work page

Privacy blog page

Clean, simple CSS structure

🧩 Technologies Used
HTML5

CSS3

No frameworks, no JavaScript — just fundamentals.
