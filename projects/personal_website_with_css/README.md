# Personal Website Practice (HTML, CSS & JavaScript)

This is a simple practice project for learning basic HTML, CSS, and JavaScript. The page displays a profile photo, an introduction, fun facts, and buttons that change the page’s style.

---

## 🚀 Features
- Profile image section  
- “About me” text with fun facts  
- Newsletter input box  
- Two JavaScript buttons that change the page’s style  
- External CSS file for styling

---

## 📸 Add Your Own Photo (Important)
The HTML file includes an `<img>` tag that points to:
    linkedin_profile_pic.jpg
    
You **must replace this file with your own photo**, or update the `src` value to match your image’s filename.
