📘 Overview
This project recreates the national flag of The Gambia using HTML and CSS. It’s a simple yet effective exercise for learning how to use layout, color, and structure to represent real-world designs with web technologies.

🎨 Flag Description
The flag consists of three horizontal stripes:

Red (top): Symbolizes the sun and the savanna.

Blue (middle): Represents the Gambia River, the country’s lifeline.

Green (bottom): Stands for agriculture and the forests.
Each colored band is separated by a thin white stripe, symbolizing peace and unity.

🧱 Technologies Used
HTML5 for structure

CSS3 for styling and layout
